# Иллюзия данных 
![Версия](https://img.shields.io/badge/version-0.0.2-orange?style=plastic)

Приложение для создания правдоподобных источников данных.

## Установка

```bash
git clone --depth 1 --branch v.0.0.2 https://github.com/chronosavant/data-illusion.git 
cd data-illusion
```

## Конфигурирование

На данный момент конфигурирование не требуется.

## Использование

```bash
python main.py
```
Результат расположен в каталоге output.

## Изменения версии v.0.0.2

- `[new]` Добавлена генерация мужских имен.
- `[new]` В справочник фамилий добавлено обозначение пола.

## Функционал

Генерируется файл `dict_persons.tsv` со статичным списком из 1000 человек мужского пола, каждый человек определяется фамилией и именем. Фамилия и имя выбираются произвольно (с равномерным распределением) по списку общерусских мужских фамилий и наиболее частых мужских имен.
