# Иллюзия данных 
![Версия](https://img.shields.io/badge/version-0.0.6-orange?style=plastic)

Приложение для создания правдоподобных источников данных.

## Установка

```bash
git clone --depth 1 --branch v.0.0.6 https://github.com/chronosavant/data-illusion.git 
cd data-illusion
```

## Конфигурирование

На данный момент конфигурирование не требуется.

## Использование

```bash
python main.py
```
Результат расположен в каталоге output.

## Изменения версии v.0.0.6

- `[new]` Добавлена генерация суррогатного ключа (автоинкремент).

## Функционал

Генерируется файл `dict_persons.tsv` со статичным списком из 1000 человек разного пола, каждый человек определяется фамилией, именем, отчеством и датой рождения. Фамилия, имя и отчество выбираются произвольно (с равномерным распределением) по списку общерусских фамилий и наиболее частых имен (и произведенных от них отчеств). Дата рождения выбирается произвольно из диапазона от 14 до 90 лет с момента генерации. Создается суррогатный ключ в виде автоинкрементального счетчика.
